# AWS Document RAG

A portfolio project for an owner-isolated document question-answering application on AWS.
Authenticated users will upload private documents and receive answers grounded only in their
own retrieved content.

## Current status

Phase 0 establishes local contracts, a React/TypeScript shell, a resource-free SAM template,
and offline CI. No AWS resources have been created.

Read [the plan](PLAN.md), [progress checkpoint](docs/plan/PROGRESS.md), and
[local development guide](docs/development.md) to continue safely.
